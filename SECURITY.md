# Security Policy

These are educational example packs, but we still take security seriously.

## Reporting a vulnerability

Do not open a public issue for a security problem. Email **ernesto@huitzo.ai** with:

- a description of the issue and where it is (file or pack),
- steps to reproduce,
- the impact you expect.

We will acknowledge within a few business days and keep you updated as we work a fix.

## Scope

This repo teaches usage of the Huitzo SDK and CLI. Vulnerabilities in the platform itself should still be reported to ernesto@huitzo.ai; we will route them to the right team.
